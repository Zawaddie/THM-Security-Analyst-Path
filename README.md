## Introduction
The Security Operations Center (SOC) is a central hub for securing many large organizations, and junior analysts are among the most numerous and demanding roles in a SOC. 
In the analyst role, you will work with logs, triage and prioritize alerts, collaborate with your teammates and other departments, and be the first line of defense in reacting to cyber incidents. 
This comprehensive path covers the necessary technical and operational skills to make you a qualified, universal SOC analyst.

## THM Security Analyst Status: COMPLETED

Completed the **TryHackMe Security Analyst Path**, gaining hands-on experience in detecting, analyzing, and responding to security threats across enterprise environments. This path focuses on the *defender’s perspective*, emphasizing real-world SOC operations, threat detection, and incident response workflows.

### 🔍 Core Competencies

* **Security Monitoring & Alert Triage**

  * Analyze logs, alerts, and telemetry from SIEM and EDR tools
  * Distinguish false positives from true security incidents
  * Prioritize alerts based on risk, impact, and threat context

* **Threat Detection & Analysis**

  * Identify malicious activity using behavioral indicators and IOCs
  * Detect common attack techniques mapped to **MITRE ATT&CK**
  * Investigate malware, phishing, brute-force, and lateral movement activity

* **Incident Response**

  * Perform initial incident triage and containment actions
  * Collect and analyze forensic artifacts (logs, network traffic, endpoints)
  * Document findings and recommend remediation steps

* **Network & Endpoint Visibility**

  * Analyze network traffic using tools like Wireshark and Zeek
  * Investigate endpoint activity and suspicious process behavior
  * Detect command-and-control (C2) and data exfiltration patterns

* **Threat Intelligence & Reporting**

  * Enrich alerts using threat intelligence feeds
  * Correlate events across multiple data sources
  * Produce clear, actionable incident reports for stakeholders

### 🧠 Analyst Mindset

* Defender-first thinking: focus on **visibility, detection, and response**
* Strong attention to detail and investigative curiosity
* Comfortable working under pressure in alert-driven environments
* Security decisions guided by evidence, context, and impact

### 🛠️ Tools & Technologies

* SIEM concepts and log analysis
* Wireshark, Zeek, Sysmon
* Threat intelligence platforms
* MITRE ATT&CK framework
* Windows & Linux log analysis

### 📌 Outcome

This path strengthened my ability to operate as a **SOC / Blue Team Security Analyst**, capable of identifying threats early, responding effectively, and supporting organizational security posture through continuous monitoring and analysis.
